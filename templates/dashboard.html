How submissions work

A push is registered when this service receives its GitHub webhook. You can also register the current branch commit here before the deadline. The latest eligible registered commit is your submission. Commits received after the deadline are not backdated.

GitHub Actions provides feedback. Official points come from an independent run of the public tests for the recorded commit. Private checks may adjust or invalidate those points; the grading report records the reason. Integrity failures need review and are not automatic misconduct findings.

Repository access may become read-only after the deadline. This does not extend the submission cutoff.
